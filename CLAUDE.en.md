# Claude Code project guide

[简体中文](CLAUDE.md) · **English**

See [AGENTS.en.md](AGENTS.en.md) for shared project guidance. Run commands from the rpynx repository root. When diagnosing compatibility issues, inspect logs and importer settings first to identify the importer, loader, or engine runtime as the source. Report host tests, cross-builds, and hardware tests separately. Preserve existing changes and stage only files relevant to the current task. Keep original hardware records in English under `tests/hardware/results/`.
